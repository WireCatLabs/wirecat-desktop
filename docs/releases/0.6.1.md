WireCat 0.6.1 adds Only this computer, reading pictures on request, and an agent and a model for each digest. Digests can read Google Drive, Google Calendar and your CRM, and you can change a finding before you approve it. Most of this needs Memo 0.131.86 or newer: WireCat offers the update.

## New

- **Only this computer.** One switch in Settings keeps every model call of every WireCat tool on this computer. A model on another computer is refused before anything is sent. Under the switch, a list shows where each feature sends data now: this computer, another computer, or through your agent. An agent may turn it on, only you turn it off.
- **Reading pictures, on request.** A new setting chooses Never or On request, the agent that reads (Claude Code or Codex) and an optional model. Only you turn it on, and the setting says plainly that the picture goes to that agent's provider. A picture in a conversation or a search result then has "Read the picture", and its text shows under it and becomes searchable. A file the tool saved on this computer has "Open the file". Add to memory says when the AI model seems not to read pictures.
- **A digest says which agent writes it.** The digest editor has an Agent and a Model field, and a new digest starts with Claude Code. It offers the agents on this computer that Memo lets a schedule start. An agent Memo does not run on a schedule is greyed out, with Memo's reason. Codex runs only after you tick the consent box that shows under Agent when you choose it. A digest set to another agent in a terminal keeps it, and its cost limits are hidden, because that agent does not say what a run costs.

## Improved

- **Digests read Google Drive, Google Calendar and your CRM.** They show in "Takes from" when their tool is installed.
- **Rewrite records with a model at your own address.** "Rewrite records for better search" can use another model at an address, such as Ollama or LM Studio on this computer, or an OpenAI-compatible service. A plain http address on another computer is refused, and the step says why and what to use instead.
- **The AI model says what shares it.** Linking chats, reply drafts and text in attachments use the AI model when they have no model of their own, and Settings now says so. Check says plainly when a model answered nothing and seems not to read pictures.
- **No key asked of a model on this computer.** A model at a local address, not only Ollama, no longer shows a missing key warning, in Settings, Add to memory and the search settings.
- **Change a finding before you approve it.** Each waiting finding in Memory has "Edit". Change its words, why it matters or its due date, and save. An empty field is cleared. If an agent changed the findings meanwhile, Memory reads them again and says so.
- **Give a company its address on a match by name.** When a match card joins a person to a company by name only, "Company address" lets you pick which of the two addresses belongs to the company.
- **A deal shows its own tasks.** The deal dialog in Clients lists the tasks of the deal or lead and of its company, next to the tasks of its contacts.

## Fixed

- **A batch decided in part stays in part.** When some findings of a batch were approved in a terminal, Memory shows them as decided and asks only about the rest. Save decides only the findings that still wait.
- **A digest that mentions Drive, Calendar or a CRM opens.** A report item from a source WireCat has no name for shows without a source, not as the whole report in plain text.

## Known issues

- **Save the mail agent's schedule once after the update.** A mail agent schedule saved by an earlier version stops running, and the schedule list says "save it again". Open the mail agent in WireCat and save it once. Digests are saved again by themselves. A digest that Codex writes shows "Waits for you" in the Digests table until you give your consent: open the digest, tick the consent box under Agent in its settings, and save.
- **"Read the picture" on Telegram, MAX and WhatsApp messages** shows once those tools have a release that reads pictures.

## All changes

- Only this computer in Settings, enrichment at a model address, no key warning for a local model, what shares the AI model, reading pictures on request and opening saved files, the agent and model of a digest, Drive, Calendar and CRM as digest sources, change a finding before you approve it, a batch decided in part, a company address on a match by name, deal and company tasks, the agents Memo lets a digest run, Codex with your consent (#350)
