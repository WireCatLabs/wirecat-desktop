WireCat 0.5.0 is the first version with a signed Windows installer. It also checks that your tools can still read your saved data before it installs or updates one.

## New

- **The Windows installer is signed.** It carries an Open Source Developer certificate from Certum, so Windows names the publisher, Open Source Developer Viacheslav Ptsarev. Before, it showed an unknown publisher.
- **A check before you install or update a tool.** All WireCat tools keep your messages and notes in one shared store. A new version of a tool can move that store to a newer format. WireCat now checks this first. When another tool also needs its new version to keep reading the store, WireCat updates it too, right after the first one, and says so in the progress line. You see a warning only when a tool has no such version yet, or when the new version cannot open your store. Then you choose "Not now" or "Update anyway". The same check runs when you install tools during the first setup.
- **Background service for Telegram, MAX and WhatsApp.** The tool's details page has a new section that keeps the tool running in the background, for every profile. Start it, stop it, or stop it from starting at login. When something goes wrong, it says what in one sentence and offers the one fix, for example Sign in or Update.
- **Open the update command in a terminal.** A copy installed from a .deb or .rpm package needs your password to update. The update window now has an "Open in terminal" button. Type your password there, then restart WireCat when the install finishes. The command and its copy button are still there.

## Improved

- **Why the mail agent skipped a run** is now shown in your language, also in Russian and Spanish.
- **Rows on the Tools page stay in place** while other tools update above the one you clicked, and when the storage line above the list gets shorter.

## Known issues

- **Windows may still show a SmartScreen notice** for the first downloads. It goes away as more people install the signed app.
