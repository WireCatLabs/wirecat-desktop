WireCat 0.9.2 keeps your tools working when an update goes wrong.

## Fixed

- An update that fails its check no longer leaves you without the tool. WireCat installs the update once more, and if it still fails, it puts back the version you had.
- A failed build of one tool no longer stops other tools from installing or updating.
- If WireCat's own copy of pnpm is damaged, the next install or removal sets it up again.
- Removing a tool also removes its programs when the tool's folder was already gone.
- Updates no longer leave old files behind. Each update used to keep 40 to 90 MB that no tool used.
- The command shown for removing a copy works for copies WireCat installed.

## All changes

- A failed update never leaves a tool missing, and WireCat's pnpm heals itself (#498)
