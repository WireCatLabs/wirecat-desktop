WireCat 0.7.4 updates through Ubuntu's Software Updater, and lets you change an account's profile id.

## New

- **Updates through Software Updater on Ubuntu and Debian.** Installing the .deb now adds WireCat's apt repository at apt.wirecat.dev. From then on new versions arrive in Software Updater, or with `sudo apt update && sudo apt install wirecat`, and App Center shows WireCat as the developer. The update window in the app says so instead of downloading the package.
- **Change an account's profile id.** The account menu can rename a profile, keeping its sign-in, settings and data, once the tool's own new version supports it. The same menu opens the account's settings.
- **An Inbox tab in digests.** Mail sorted by the AI model.
- **Linear and HubSpot in the catalog.** Linear signs in with a pasted personal API key. HubSpot signs in through its own setup flow.
- **Google Calendar syncs from WireCat**, and shows when it last did.

## Improved

- **Digests, tasks and documents are out of beta.**
- **Mail's sync window** is a choice in Settings.
- **"Add your own tool"** is a primary button above the tool list.
- Clicking "I accept these changes" ticks the box.
