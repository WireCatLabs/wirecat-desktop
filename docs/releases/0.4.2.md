WireCat 0.4.2 adds a mail agent you can turn on from Email. It also tidies the Logs and Settings pages and makes menus work better with a keyboard.

## New

- **Mail agent.** In Email's Manage panel, the "Run on a schedule" switch starts Memo's mail agent. It reads new mail every 5 minutes and proposes tasks, invoices, orders and facts for you to accept. It never sends anything. The panel shows the last run, what today cost (with the daily limit, from the next Memo version), and how many proposals wait for you. This needs Memo and Claude Code.

## Improved

- **Logs page.** Run settings are behind a "Log settings" button, one row per tool. Long text in the runs table wraps at a narrow window and is no longer cut. Controls stay active and say what is missing, instead of being greyed out.
- **Community tools setting** is one line with a switch, an info tip and a link to the guide.
- **Menus and keyboard.** Filter chips and the More menu take focus when they open, so arrow keys and Escape work. On the Memory page, focus stays on the row after Approve, Reject or Undo approval.
- **The app starts faster.** Each page loads when you open it.

## Fixed

- **A failed skill install on the Agents page** no longer disappears when the page checks again. It stays until you retry it.

## Known issues

- **Why the mail agent skipped a run** is shown in English, as Memo says it, also in Russian and Spanish.
