WireCat 0.4.0 adds an Analytics page and lets you change or take back what WireCat remembers. Setup is easier too. Tools now work in a new terminal without extra steps, and Email, Google Calendar, Drive and Zoom have clear sign-in steps.

## New

- **Analytics page.** See how many messages you get each day, who you talk to most, how fast you reply, what waits for your answer, how many tasks you make and close, and how much data WireCat keeps. Every number comes from the tools themselves. You can pick the period and hide names.
- **Change what WireCat remembers.** On the Memory page, you can edit an approved record, mark it as no longer true, undo its approval or erase it. "Approve" now approves only the rows you see on screen.
- **Add a bot.** For Telegram, MAX and WhatsApp, the Tools page can add a bot. Its token is never shown.
- **Sign-in steps for Email, Google Calendar, Drive and Zoom.** Each step says what happens, what you will be asked and what the tool can access. For Google and Microsoft, you can use your own app instead of WireCat's.
- **Email has its own tool.** It no longer shares a package with memory.
- **Remove an unused copy of a tool.** If you have two copies of the same tool, you can remove the one WireCat does not use.
- **A first look at the app.** A start screen with the WireCat mark replaces the blank window. "Show me around" leads you to your first guide.

## Improved

- **Tools work in new terminals.** WireCat now adds the tool folders to your PATH by itself, on every system. If an AI app still cannot find a tool, one "Fix" button on the Agents page repairs it.
- **A clear wait screen when you install.** It shows the total progress, the progress of each tool, the time left and tips for what to do next.
- **Better error messages.** A full disk, a proxy, a certificate problem and long Windows paths each tell you what to do next. A network error is tried a second time on its own.
- **Telegram sign-in.** The window is wider and the text is easier to read. It does not jump between steps. WireCat checks your API keys before it sends them.
- **After an install, WireCat offers to teach your agents the new tool.**
- **Repair fixes a broken settings file** by using the tool's own repair.
- **Sync tells you about a rate limit** and shows how long to wait.
- **Help menu.** Click the version number to open it. It now shows your system, Node.js and npm.
- **Every dialog has a close button** and closes when you click outside it.
- **Logs and Memory.** The expand arrow is at the right edge, and the Logs table fits a window that is 960 px wide.
- **Documentation links open wirecat.dev.**

## Fixed

- **A tool's panel could not be closed after an update.** It closes now.
- **On Windows, tools install without administrator rights,** and tool folders return to your PATH if they go missing.
- **Names in doctor reports and bug reports** are now hidden, including chat titles and contact names.
- **WireCat accepts a tool only if it was built by that tool's own official release.** Other builds are refused.
- **The Logs page keeps the runs you start yourself,** also when they succeed.
- **Small fixes** to the scrollbar, the Storage page names and times shown in the 12 hour format.

## Known issues

- Google Calendar can be signed in, but search and sync for it are not ready yet.
- Some Analytics cards need newer versions of the tools. Until you update them, those cards say that more data will come with an update.
