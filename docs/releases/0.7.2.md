WireCat 0.7.2 adds Yandex Disk, signs beeline in inside the window, and splits Settings into the app's own and each tool's.

## New

- **Yandex Disk.** Yandex Disk is a built-in tool. Get a token on Yandex's own pages, paste it, pick folders by their path on the Disk, and WireCat copies them to this computer, the same way as Google Drive. The folder picker shows which folders hold more folders, Storage shows what the Disk's copy takes, and removing the account can keep or delete its data.
- **beeline signs in here.** Paste the Beeline Cloud PBX API token in the window, with no terminal. A tool you add yourself can now describe its own sign-in, and WireCat checks that it only runs the tool's own commands.

## Improved

- **Settings in two tabs.** WireCat holds the app's preferences, Tool settings holds each tool's. A tool's "Settings" opens its tab.
- **The agent for background jobs is short:** one line of help, the list and the button, with a line only when you need to act.
