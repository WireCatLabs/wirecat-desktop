WireCat 0.6.8 lets you add a WireCat tool that is not on the Tools list, installs every tool with one click, and gives digests their own place in the menu.

## New

- **Add a WireCat tool that is not built in.** "Add your own tool" now accepts a WireCat package that is not on the Tools list, for example `@wirecat/beeline-cli`. It goes through the same review as any other own tool. A tool that is already built in says so and points you to the Tools page.
- **Install all.** The Tools page has an "Install all" button. It installs every built-in tool that is not installed yet, one after another. Each row shows its own progress.
- **Digests in the menu.** Digests is a menu section again, after Tasks. The Digests tab shows what each digest wrote, newest day first. The Settings tab holds the schedules and each digest's settings.

## Improved

- **The bell opens the digest.** A digest notification now opens that day's report, not the digest's settings. A digest link and the notice about a failed run do the same.
- **Links in a digest open their target.** A person opens on Contacts, a meeting opens its card, a document opens its details, and a deal or a lead opens on Clients.

## Fixed

- **The Asterisk sign-in no longer hangs.** Pressing Start twice and then Cancel could leave the sign-in waiting forever on "Asking Asterisk how to sign in". Now the second start does not run.
- **Meeting times in a narrow week block.** A narrow meeting in the week view no longer cuts its time to "1…". It shows the full time, or only the start, or no time when even the start does not fit. The full time is still in the tip.

## All changes

- Add a WireCat package that is not built in as your own tool (#402)
- Install all button on the Tools page (#400)
- Digests is a menu section again, with Digests and Settings tabs (#403)
- A stale Start no longer runs the Asterisk sign-in without its database password (#399)
- A narrow week block shows the start time whole instead of cutting it (#401)
