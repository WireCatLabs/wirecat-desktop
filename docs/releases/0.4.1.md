WireCat 0.4.1 fixes app updates on Linux and a wrong "two copies" warning on Windows. It also adds a way to take back a memory an agent wrote, and a Tailscale Funnel setup that needs no Tailscale app.

## New

- **Take back an agent's memory.** On the Memory page, "Undo approval" puts a fact an agent wrote back into To review. A fact you wrote yourself keeps Edit and Erase. This needs Memo 0.131.28 or newer.
- **Tailscale Funnel without the Tailscale app.** When Tailscale is not installed, the "Tailscale Funnel" choice uses WireCat's own small connection. It needs no administrator password. If you have the Tailscale app, WireCat still uses it.
- **Zoom meeting counts on Analytics** come from Zoom's own meeting history when you have Zoom tool 0.67.0 or newer.

## Improved

- **Clear messages when an update fails.** Each common problem says what happened and what to do: no internet, GitHub not answering, not enough space in Downloads, or Downloads not writable. Technical details go in a small line below.
- **Before the system asks for your password,** WireCat says what happens if you cancel: nothing is installed, and the package stays in Downloads.
- **The bot list for Telegram, MAX and WhatsApp** works with the tools' newer versions. An older tool is asked to update.
- **Release notes** in the update window are now short and readable.

## Fixed

- **Updating a .deb or .rpm copy failed** with "The update's package has an unexpected name". It works now. Copies on 0.4.0 or older must install 0.4.1 by hand one time, from the download page. After that, updates work from inside the app.
- **On Windows, one tool could show as two copies,** one of them unable to start. WireCat now counts one copy per folder, the one your terminal runs.

## All changes

- Count one copy per folder on Windows, not each file npm makes for a tool (#111)
- Name the .deb and .rpm update from its version, and explain why a download failed (#110)
- Plain-language release notes, written before each release (#109)
- List MAX bots without a placeholder profile (#108)
- List Telegram and WhatsApp bots without a placeholder profile (#107)
- Undo approval of an agent's fact on the Memory page, and Zoom meeting history on Analytics (#103)
- Tailscale Funnel through WireCat's own connection, with no Tailscale app and no password (#102)
