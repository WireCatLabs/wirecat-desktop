# Guides

Short rules for each kind of change. Read the one for your task before you write code.

Each guide marks its rules:

- **Today**: true in the code now. Follow it.
- **Target**: true after the refactor in [the architecture report](../architecture-report.md#migration-plan). Follow
  it in new code when the step it needs is done, and do not undo it where it is done.

| Task | Guide |
| --- | --- |
| A new page in the sidebar | [new-screen.md](new-screen.md) |
| A new component or a change to one | [new-component.md](new-component.md) |
| Where a rule, a fetch or a state goes | [application-logic.md](application-logic.md) |
| A new Rust operation | [rust-command.md](rust-command.md) |
| Tests | [testing.md](testing.md) |
| Text on screen | [i18n.md](i18n.md) |
| A release | [release.md](release.md) |
| Before you write anything new | [reuse.md](reuse.md) |
