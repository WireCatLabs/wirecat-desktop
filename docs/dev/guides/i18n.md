# Text on screen

The app speaks English, Russian and Spanish ([i18n/index.ts](../../../src/i18n/index.ts)).

## Rules

- **Today.** Every word a user sees or hears is in a messages file: `messages.tsx` (or `messages-<part>.tsx`) in the
  feature. Copy [system/messages.tsx](../../../src/features/system/messages.tsx): an `en` object, then `ru` and `es`
  of the same shape, exported as `Messages<typeof en>`.
- **Today.** A component reads them with `const m = useMessages(systemMessages)`. Code outside React uses
  `messagesOf`, and its component must also read `useLang()`.
- **Today.** A message with values is a function, so each language orders its own words:
  `` missing: (program: string) => `${program} missing` ``. Counts use `plural(lang, n, forms)`.
- **Today.** [no-literals.test.ts](../../../src/i18n/no-literals.test.ts) fails on a text literal in JSX or in a
  shown prop (`title`, `aria-label`, `placeholder`, `alt`, `label`) outside a messages file. Product names in its
  `KEEP` list pass.
- **Today.** [catalogs.test.ts](../../../src/i18n/catalogs.test.ts) fails when `ru` or `es` misses a key or a slot.
- **Today.** Text sent to the team (bug report fields) stays English.
- Write plain short sentences. Say what happens next. Rule 9 asks a finished flow to say so plainly.

## Checklist

1. All three languages written, not copied English.
2. No literal in JSX.
3. `pnpm test src/i18n` green.
4. Long Russian and Spanish strings checked in a capture: they are often 30 percent longer.
