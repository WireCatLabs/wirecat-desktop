## 3. Находки

**IDEA-27 · CRM CLI `b24` не попадает в основной список инструментов, а стоит в отдельном блоке внизу, вроде «Marketplace».**
Решение владельца 2026-11-06 (cli-private, journal/2026-11-06-bitrix24-cli.md, NEED-2284): новый CLI `b24`
(`@wirecat/bitrix24-cli`, в npm его ещё нет) не показывать среди основных инструментов, чтобы не путать обычных
пользователей. Идея владельца: отдельный блок внизу страницы инструментов для b24 и будущих CRM и бизнес-CLI. Пока ничего
не сделано. Когда дойдёт до дела: по правилу 7 (CLAUDE.md) у инструмента в `catalog/tools.json` появится признак группы,
а страница Tools покажет эту группу отдельным блоком.
