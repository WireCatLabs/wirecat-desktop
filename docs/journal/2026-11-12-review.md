## 3. Находки

**BUG-11 · `CopyTextButton` из 0.6.2 показывал «Copied», даже когда копирование не удалось (повтор BUG-6)**
Найдено при сборке веток: новая копия кнопки пришла из релиза 0.6.2. Заменена на `CopyButton`, сам файл удалён (#356).

**BUG-12 · Ошибка удаления в Storage исчезала сразу**
Ошибка удаления и ошибка чтения страницы лежали в одном поле `error`. Перечитывание страницы после удаления стирало это поле. Кроме того, текст был «не удалось прочитать папки».
Исправлено: у удаления и открытия своё поле `actionError` (`src/shared/storage-store.ts`), есть тест (#356).

**DEBT-33 · Агенты в соседних worktree перепутали `git stash`**
Список stash общий для всех worktree одного репозитория. Один агент применил чужую незаконченную работу, у другого исчезла своя правка. Восстановлено.
Правило «не использовать stash» записано в бриф и в память.

**FIND-14 · Окно обновления, вероятно, не показывает release notes**
`scripts/latest-json.sh` пишет `"notes": ""`. Это вывод из кода, не проверено. Записано в BACKLOG.md.

**FIND-15 · В API Телемоста нет чтения конспекта, расшифровки и записи**
В OpenAPI есть только встречи, соведущие и настройки организации. Конспект и ссылка на запись приходят письмом. API доступен только Яндекс 360 для бизнеса.
