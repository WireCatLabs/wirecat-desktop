## 3. Находки

**FIND-195 · Задача из одобренного действия открывается по id, не по ключу**
memo пишет в `result.task` id задачи (UUID), а страница Tasks работает с ключами (`REQ-22`). `memo tasks show`
принимает id (проверено по `--help` 0.131.16), поэтому `task_board::show` теперь принимает и id. На реальных данных
не проверено: что карточка такой задачи (инбокс-проект `IN…`) читается парсером Tasks — вывод, не проверка.
