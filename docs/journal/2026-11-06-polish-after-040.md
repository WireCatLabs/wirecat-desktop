## 2. Вопросы Славы

**ASK-69 · «is there no way to update deb without user actions? mb tauri allows update in place etc»**
Нет, не без действий пользователя. `tauri-plugin-updater` 2.14.1 ставит .deb через `pkexec`, затем `zenity`/`kdialog`
+ `sudo`, затем `sudo` в терминале (`updater.rs`, около строки 1382). Правило 6 запрещает права администратора,
поэтому WireCat передаёт .deb/.rpm системному установщику (`src-tauri/src/package_update.rs`). Тихие обновления дал бы
только свой apt-репозиторий.
