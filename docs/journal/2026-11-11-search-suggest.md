## 3. Находки

**UX-207 · Пустое поле поиска без выбранного инструмента показывало только два готовых запроса**
`useSuggest` давал пустой список ключей, пока инструмент не выбран (`SearchPage.tsx`, `NO_FIELDS`), и
`suggestSearch` выводил только `examples()`. Так выглядел скриншот 56. Исправлено (TASK-1).

**BUG-729 · cli-core: точное совпадение имени прячет тех, чьё имя его только содержит**
`pickPerson` (cli-messaging `src/resolve.ts`, строка `exact.length > 0 ? exact : …`) берёт только точные
совпадения, если они есть. Два контакта «Ярослав» → контакт «Ярослав Фамилия» не попадает в кандидаты. `pickChat` в том же
файле делает наоборот. Ищет по `identities.name`, `username` и псевдониму аккаунта одного профиля
(`senderAmong`, `store/sqlite/identities.ts` `people`), но не по имени связанного человека (email-связь).
Предположение, не проверено на его данных: в Telegram у контакта имя с фамилией.

**UX-208 · «Составить запрос» вставлял запрос, не проверив его**
Теперь проверка поиском с лимитом 1 (TASK-3).
