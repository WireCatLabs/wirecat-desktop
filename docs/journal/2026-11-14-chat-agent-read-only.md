(cli-private): каждый предложенный профиль становится только для чтения, группа, которую владелец заблокировал, остаётся
заблокированной. Рядом с переключателем одно предложение о риске на трёх языках.

## 3. Находки

**FIND-277 · Блокировка по умолчанию мешала синхронизации**
Со слов постановки: после подключения чат-агента синхронизация его профилей, переведённых в `readonly`, вставала.
Сам в этой сессии не проверял. Это и было поводом для NEED-2602.

**DEBT-64 · WireCat не запоминает уровни, которые были до «только чтения»**
`src/features/agents/connect-flow.ts` читает уровни до записи (`before`), но только чтобы не открыть заблокированную
группу и чтобы назвать команды, которые запись открыла; никуда их не сохраняет. Поэтому выключение переключателя не
возвращает прежние уровни: интерфейс говорит это прямо и отправляет в «Разрешения» инструмента. Чтобы откатывать,
нужно сохранять `before` для каждого профиля и группы при подключении; не сделано, чтобы не угадывать уровни у уже
подключённых агентов.
